# NaijaBuild

**Beautiful AI Website Builder made for Nigeria**

Build professional websites in minutes using AI. Pay in Naira. Hosted for you.

## Vision
An easy, beautiful, and practical AI website builder designed specifically for Nigerian users and businesses — not a copy of international tools.

## Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui style
- Paystack (Naira payments)
- AI generation (DeepSeek / Qwen / Groq)

## Status
Under active development.

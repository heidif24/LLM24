# NaijaBuild

**Beautiful AI Website Builder made specifically for Nigeria**

Create professional websites in minutes using AI. Pay in Naira. Hosted for you.

## Vision

Most AI website builders are built for Western markets. NaijaBuild is designed for how Nigerians actually start and run businesses:

- Extremely simple interface
- Pay in Naira (Paystack)
- Examples that make sense locally (churches, boutiques, freelancers, schools, event planners)
- Mobile-first (most users are on phones)
- WhatsApp-friendly contact options

## Current Status

- Beautiful landing page
- Complete Build flow (prompt → generation → preview)
- Pricing page in Naira
- Login skeleton
- Clean modern UI with green Nigerian-inspired theme

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide icons
- Ready for Paystack + AI providers (DeepSeek / Qwen / Groq)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
